The single sentence that could have replaced an entire pointless meeting: it could have been one email, but instead twelve people spent an hour deciding to schedule another meeting about it. No context, no explanation — just the line that kills the meeting.

## The line

> This meeting could have been one email, but instead twelve of us spent an hour deciding to schedule another meeting about it.

## Run it

```sh
node main.ts
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It kills the meeting twice: first by naming the email that should have replaced it, then by revealing the meeting's only output was another meeting. Twelve people, one hour, zero decisions — the most relatable sentence in office life, and the meeting's own verdict.
